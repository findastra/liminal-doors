Tools tracker

Reading the ledgers…

  • A tool: add it to the world’s ledger under tools (name, does, path), then put its id in every_floor, whole_world or under its floor number in floors. Use the same id in every world.
  • A world: add a row to worlds in tools-tracker-20261019.json that points at the world’s ledger. The ledger has the same shape as Liminal Doors’.
  • Getting better: in the same file, add {"date", "by", "world", "floors", "note"} to tools.<id>.getting_better. When a tool is ready, set its readiness to ready to package.

The two lights only work in this browser. They are not the Farm’s kill switch.
