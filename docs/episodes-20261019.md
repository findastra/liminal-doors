# Liminal Doors: nine episodes, 333 places (Astra, 2026-10-19)

Nine episodes of 37 floors make 333 places. Each episode has its own release date: the third Friday of every other
month, starting Friday, January 15, 2027. Floor numbers keep counting across episodes, all the way to 333.

Astra wants the project to show how she gets better at using AI over time. In her words, "the world itself is the
model." So the page doesn't add commentary. Instead, the tools used on each floor are tracked in
`docs/tools-by-floor-20261019.json`, and the Collection page's T button reads that file. Over time it shows which tools
improved, so the finished toolkit can be packaged.
