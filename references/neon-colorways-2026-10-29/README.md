# Neon Liminal Doors — 10 Color Studies (2026-10-29)

Status: **Concept index only — full-resolution PNGs still need upload.**

This set was generated in ChatGPT as a 2 × 5 image sheet, then split into ten concepts for archiving. The original assets and downloadable ZIP remain in the source conversation, not yet in this Git repository.

## Art direction

- Flooded, tiled corridors with deliberately simple, VRChat-friendly geometry.
- Deep almost-black vanishing point; actual conventional door centered at the far end.
- High color juxtaposition, bloom, water reflections and custom-shader potential.
- Liminal and charming rather than horror or ornamental fantasy.
- Landscape composition, environmental context visible around the far door.

## Color studies (left-to-right, top row then bottom)

1. Magenta / deep indigo

5. Violet / hot pink

8. Indigo / ultraviolet
9. Acid lime / dark green
